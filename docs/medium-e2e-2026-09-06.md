# Medium image production trial

## Scope and configuration

The operator authorized an animated advertisement initiated in the production web UI with GPT Image 2 Medium, a reported $5.11 OpenAI balance, and up to $1 of additional infrastructure. The test project is `b672e1a4-ae3c-49fa-a19f-1cc419e83a58`. It uses an existing Allbirds brand profile and an uploaded animated reference; this is not a fresh-account onboarding test.

The approved 32-word English script produced a 12.852-second narration and five scenes. Images use `gpt-image-2`, `medium`, `1024x1536`; clips use MiniMax H3 eight-step generation. Narration comes from the configured MiniMax API. The final renderer and quality review run in the production worker.

## Recovery and changes

Two early director attempts failed before image generation. The director schema now states the same character limits enforced by validation, and diagnostic logs record lengths rather than full prompts. Those earlier failures did not retain enough diagnostics to prove their exact cause.

Production `735c4bbb-58df-4ee4-911c-6a87839a0bc8` saved narration and all five images before failing because the GPU worker was not yet available. A web retry, production `d47efa07-aa22-4d5a-8f3a-d84f5a894a98`, reused those media assets. No second batch of images was generated.

An operator-only, expiring production-attempt allowance allowed the test account to resume without removing history or weakening the normal five-attempt daily limit. Three Medium provider tests and fifteen production tests passed. A separate diagnostic director call validated a five-scene plan; delivered media generation was initiated through the website.

## Image cost evidence

All five image responses retain usage, request ID, model, size, quality and reference count. Using published GPT Image 2 rates of $5/M text input tokens, $8/M image input tokens and $30/M image output tokens, their combined image cost is **$0.348616**. Each output used 1,372 tokens ($0.04116 output alone). This total includes image-generation inputs, but excludes reference transcription, DeepSeek, MiniMax and infrastructure.

The authenticated OpenAI billing screen showed **$4.76 remaining at 05:48 UTC**, down from $5.11, with auto-reload still off. MiniMax reported 204 billed characters using `speech-2.8-hd`.

The estimate-based production admission limit was $1.75 for this project and globally. Reservations include failed or ambiguous operations and are not supplier invoices. Standalone chat and reference analysis are outside this admission ledger.

Pricing references: https://developers.openai.com/api/docs/pricing and https://developers.openai.com/api/docs/guides/image-generation#calculating-costs

## Completion

Render `1d26daa7-7a1e-4ec7-b29f-8b4a8952f343` completed: 1080x1920, 12.833 seconds, video and audio streams, 10,598,115 bytes. A private local review copy was saved without changing the delivery gate. The production did **not** pass delivery: Flash requested an image repair, and the spending limit stopped that additional generation with `PRODUCTION_BUDGET_EXCEEDED`.

The review used `deepseek-v4-flash-vision-exp`, reporting 10,023 input and 3,263 output tokens (13,286 total). It confirmed scene two's composition mismatch, but did not flag scene four's visible collage. This is a false negative in the current quality review; the pipeline cannot yet be called reliable for unattended premium delivery. A formatting retry was also needed after an overlong review field. This test does not isolate Medium versus High: the prompt/context and the review instructions are confounders, and there was no matched High rerun.

The GPU was stopped at 05:57 UTC and the disposable pod deleted after copying the clips and logs. RunPod inventory was verified empty. Rough elapsed-time infrastructure estimate is $0.90 including setup attempts and Render, below the authorized $1; RunPod's current-hour billing feed was incomplete at inspection and is not an exact invoice. The production admission limits were reset to zero and the test-account attempt allowance expired. The optional GPU idle controller was not enabled; manual shutdown is not proof of automatic shutdown.

Render suspension was verified in its dashboard at 06:02 UTC: “Suspended by you” and “You are not billed for suspended services.” The website correctly displays that the generation budget was reached and existing progress was retained.

## Review observations during generation

The second generated still shows a shoe on a walking foot, although scene two requests a macro of wool and the sole edge. The ComfyUI history maps the second job to its correct reference and output, so this is image-direction adherence rather than swapped clip files. H3 follows that supplied first frame. A pre-animation still review would catch this before spending GPU time. Medium's visible texture quality alone does not establish that it follows every requested composition.

The fourth clip starts with a three-panel collage and transitions into a single shoe shot, contrary to the single-shot instruction. This is a material defect, not merely an aesthetic preference. The fifth clip is allowed to finish so the complete production render and quality gate can be evaluated. The admission limit was reduced to $1.52 before completion: exactly the remaining planned clip, render and review reservations fit, but additional repair generations do not. This protects the authorized infrastructure budget while retaining the trial evidence.
