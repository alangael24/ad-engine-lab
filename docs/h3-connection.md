Deploy `workers/h3-worker.mjs`, `workers/h3-adapter.mjs` and `workers/workflows/h3.json` together on a Node 22+ host with private access to ComfyUI. Configure `CREATIVE_RUSH_URL`, `GENERATION_WORKER_TOKEN`, `H3_WORKER_ID`, `COMFY_URL` through a protected environment file. Keep ComfyUI bound to localhost.

Deploy `workers/wrangler.toml` with the same token and app URL to sweep expired jobs every minute. Only activate `GENERATION_ENABLED=true` after a real clip succeeds. A GPU worker advertises availability through its fresh heartbeat; when no worker remains, the web stops accepting new generation reservations.

```sh
node --test tests/h3-worker.test.mjs tests/generations-api.test.mjs tests/generations-db.test.mjs tests/production.test.mjs
```

Opt-in live GPU test (incurs compute, uses an isolated database and storage, never customer balances):

```sh
H3_LIVE_URL=http://127.0.0.1:8188 \
H3_TEST_IMAGE=/absolute/path/reference.png \
H3_TEST_OUTPUT=/absolute/path/new-test-directory \
node tests/h3-live.mjs
```

The test exercises image registration, reservation, worker lease, real H3 execution, MP4 storage/download and idempotent retry. It refuses to overwrite an earlier started run. Inspect the previous GPU submission before using a new directory after a failure.

This connects clip generation. Full automatic image generation and voice synthesis still require separately configured providers; activating H3 does not prove those stages or the complete chat production flow.
