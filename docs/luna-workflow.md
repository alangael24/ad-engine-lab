# Historical Luna routing (retired)

The September 7 configuration used Luna for chat, references and the legacy video-use editor. It is superseded by [Astra + DeepSeek routing](astra-deepseek-workflow.md).

New calls use Astra for chat coordination, reference interpretation, production direction and final visual review; DeepSeek handles script writing, H3 prompts, primary material image inspection and structured editing. Luna and Sol are not selectable production models.

Historical filenames and stored EDL schemas named `sol-luna-v1` remain readable. They do not enable legacy model requests. The active profile is exclusively `astra-deepseek-v1`.
