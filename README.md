# CreativeRush AI

Landing page, campus privado, curso y herramienta de generación para la oferta
de CreativeRush AI.

## Desarrollo

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
```

## Desplegar en Cloudflare Pages

```bash
npm run deploy
```

Las credenciales de Stripe y Supabase deben configurarse como variables de
entorno de Cloudflare. No se guardan dentro del repositorio.

Sitio: https://creativerushai.com/
